## 🧭 Overview
Send messages between same-origin tabs with the native BroadcastChannel API. The app runs locally and uses native browser APIs; no account or remote service is required.

## ✨ Features
- 📡 Connect tabs to a named channel
- 🪪 Identify the sending tab and inspect message timestamps
- 🔌 Switch channels and close the active channel safely

## 🎬 Demo
Start the local server and interact with the controls. No hosted demo is claimed.

## 🚀 Quick Start
```bash
npm start
```
Open http://localhost:4173.

## 🧰 Tech Stack
- 🧩 Node.js and browser JavaScript
- 🔒 Local-first; no telemetry or API key
- 📦 No runtime dependencies
